# ThermoShift Project Brief — Hanium DreamUp

## 한 문장 정의

ThermoShift는 재실 상태와 재실 열부하, 미래 열환경을 추정하여 쾌적도와
전력 사용을 동시에 고려하는 소규모 공간용 실시간 최적제어 시스템이다.

## 해결하려는 문제

- 고정 온도 제어는 공실이나 이미 쾌적한 상황에서도 불필요하게 동작한다.
- 에너지 절감만 우선하면 재실자의 온열 쾌적도가 악화될 수 있다.
- PIR 단독 감지는 움직임이 적은 재실자를 놓칠 수 있다.
- 소규모 공간은 고가 BEMS를 도입하기 어렵다.

## 현재 프로토타입

- 20×20×30cm, 12 L 목업
- 펠티어 냉각과 최대 10 W 히팅패드 합성 열부하
- 온도·습도·CO₂·PIR·문 센서
- HMM 재실 상태 추정
- grey-box RC 열모델 및 예약 예냉
- PMV 기반 쾌적 penalty를 포함한 Economic MPC 프로토타입
- 실제 제어, 로그, API, 대시보드, 장애 시 로컬 버퍼

## 검증 범위

목업은 폐루프 데이터 흐름, 안전 로직, RC 파라미터 식별 가능성, 제어기
비교 절차를 검증한다. 목업 파라미터나 결과를 실공간에 1:1 이전하지 않는다.
실공간 적용 시 열·환기 파라미터를 현장에서 다시 식별한다.

현재 보유 데이터는 개발 과정에서 수집되어 통제 조건과 ground truth가
충분하지 않다. 공식 성능 수치에는 사용하지 않고 새 실험 프로토콜로
`[MEASURED]` 결과를 수집한다.

## 성공 기준

- 센서 입력부터 물리 제어 출력과 검증 로그까지 폐루프 시연이 가능하다.
- 제어 판단마다 관측값, 모델 상태, 차단 사유를 설명할 수 있다.
- 동일한 통제 외란에서 baseline과 MPC를 반복 비교한다.
- 에너지, 쾌적 허용대역 이탈, 스위칭 횟수를 분리 보고한다.
- 모든 결과에 `[MEASURED]`, `[SIM]`, `[TARGET]` 근거 라벨을 붙인다.

세부 주장 기준과 심사 대응은 [`submission-guide.md`](submission-guide.md)를
참고한다.
